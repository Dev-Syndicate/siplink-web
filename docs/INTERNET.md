# 3. STATIC IP

## Static IP

### A Fixed Internet Address for Your Business

A Static IP provides a fixed public Internet address that remains consistent instead of changing periodically.

For businesses that need predictable inbound access or IP-based security controls, a static IP can make network and application management easier.

Static IPs are commonly used for VPN access, IP allowlisting, hosted applications, remote access, servers, surveillance and business communication systems.

### What is Static IP?

A static IP is a public IP address assigned to your business connection that remains fixed.

Unlike a dynamic IP address, which may change, a static IP provides a consistent address that can be configured in:

- Firewalls
- VPNs
- Servers
- Cloud applications
- Remote-access systems
- IP allowlists
- DNS
- Security systems

### Simple Example

Your office may need to allow employees or authorized systems to connect remotely.

With a fixed public IP, the network administrator can configure access rules around that known address.

### Business Uses of Static IP

1. **Remote Access** — Access business systems securely from approved locations.
2. **VPN** — Configure site-to-site or remote-access VPN connections using a fixed public address.
3. **IP Allowlisting** — Allow approved IP addresses to access applications, cloud platforms or partner systems.
4. **Business Applications** — Some hosted applications and enterprise systems require fixed IP-based access controls.
5. **VoIP & SIP** — Support IP-based voice configurations where fixed addressing is required.
6. **CCTV & Remote Monitoring** — Provide predictable external access for appropriately secured monitoring systems.
7. **Server Hosting** — Businesses hosting approved services can use a fixed public IP for consistent external access.
8. **API & Cloud Integrations** — Some applications require a fixed IP to identify and authorize incoming connections.

These use cases are consistent with common business static-IP requirements identified by Indian enterprise connectivity providers.

# FAQ SECTION

## Business Internet FAQs

### What is Business Broadband?

Business broadband is an Internet service designed for business locations and everyday business applications such as cloud software, email, video conferencing, VoIP and web applications.

### What is Dedicated Internet?

Dedicated Internet provides a dedicated connectivity service designed for businesses that require predictable bandwidth, higher service assurance and support for business-critical applications.

### What is the difference between Business Broadband and Dedicated Internet?

Business broadband is generally intended for everyday business connectivity, while dedicated Internet is designed for organizations with stronger requirements for dedicated bandwidth, performance, reliability and SLA-backed service.

Industry providers make the same distinction between shared broadband-style connectivity and dedicated enterprise Internet.

### What is a Static IP?

A Static IP is a fixed public IP address assigned to your Internet connection. It can be useful for VPNs, remote access, IP allowlisting, hosted applications, VoIP and other systems that require a consistent Internet address.

### Do I need a Static IP for my business?

Not every business needs one. It can be useful when your business uses VPNs, remote-access systems, IP allowlisting, hosted services, certain VoIP configurations or other applications requiring fixed addressing.

### Can SIPLINK provide Internet for multiple offices?

Yes. SIPLINK's network portfolio includes VPN, dedicated connectivity and multi-location-oriented network services.

### What is SD-WAN?

SD-WAN is a software-defined approach to managing wide-area networks. It can provide centralized control over routing, application traffic, connectivity paths and network policies across multiple locations.

### Can SIPLINK manage my router and firewall?

SIPLINK can provide managed network solutions where the applicable service includes managed router/firewall capabilities. The exact equipment, features and management scope depend on the deployment.

### Can SIPLINK provide business Wi-Fi?

Business Wi-Fi can be offered as part of a broader network deployment, subject to site requirements and technical feasibility.

### Can SIPLINK connect my branches?

Yes. Multi-location connectivity can be designed using appropriate combinations of Internet, VPN, SD-WAN and managed network infrastructure.

### Does SIPLINK provide SLA-backed Internet?

SIPLINK's current Internet content references SLA arrangements for its Internet services. The applicable uptime, response, restoration and performance commitments should be confirmed in the service-specific SLA.

### Can SIPLINK provide a backup Internet connection?

Backup connectivity can be designed where technically and commercially available. A redundant link can be used for business continuity and failover.
